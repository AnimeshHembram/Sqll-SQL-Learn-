This module teaches the five parts of SQL you will use in almost every query: `SELECT`, `FROM`, `WHERE`, `ORDER BY` and `LIMIT`. **No previous experience is needed.** If you have ever used a spreadsheet, you already understand most of the ideas.

Every lesson uses the same small, imaginary bookstore. Most examples use its `books` table, which has just six books, so you can check every result by eye. Seeing one table again and again lets you focus on what each new keyword changes. Every result shown in these lessons has been checked against a real SQLite database.

**How to use each lesson:**

1. Read **The big idea** first. It explains the concept in plain words, without any SQL.
2. Look at the **Syntax**, then work through the **Examples**. Press **Run** under any example to run it yourself; the app shows the real result and checks it against the table in the lesson.
3. Press **Open in Practice** to copy an example into the Practice space, where you can change it and see what happens. Nothing you do there can break the lessons: every lesson example runs on a fresh copy of the data.
4. Do the **Try it yourself** tasks in the Practice space *before* you read the answers. Getting a query wrong, and then working out why, is how SQL sticks.

When you finish, the **Summarising data** module shows you how to count, add up and group rows.
