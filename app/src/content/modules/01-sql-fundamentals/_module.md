This module teaches the five parts of SQL you will use in almost every query: `SELECT`, `FROM`, `WHERE`, `ORDER BY` and `LIMIT`. No previous experience is needed.

Every example uses the same small table, `books`, from an imaginary bookstore. Seeing one table again and again lets you focus on what each new keyword changes. Every result shown in these lessons has been checked against a real SQLite database.

For now, read each query and compare it with the result under it. Running queries yourself arrives with the practice space in a later update.
